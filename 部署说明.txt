============================================
  拼多多 AI 客服 —— 完整部署指南
============================================

架构图:
 买家在拼多多发消息
     ↓
 Chrome 浏览器打开 mms.pinduoduo.com
     ↓ content.js 自动检测新消息
     ↓ POST 到你的服务器
 你的服务器 (Flask + DeepSeek)
     ↓ AI 生成回复
     ↓ 返回 {"reply": "..."}
 content.js 填入输入框 → 点击发送
     ↓
 买家看到回复


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  第一步: 部署服务器端
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 将文件上传到服务器

   在你本地电脑的 PowerShell 中运行:

   scp "E:\ai客服\server.py" root@34.81.122.137:/root/
   scp "E:\ai客服\setup_server.sh" root@34.81.122.137:/root/

2. SSH 登录服务器

   ssh root@34.81.122.137

3. 运行部署脚本(推荐,一键完成)

   chmod +x setup_server.sh
   sudo bash setup_server.sh

   脚本会自动:
   - 安装 Python3 和依赖
   - 引导你输入 DeepSeek API Key
   - 创建 systemd 服务(崩溃自动重启)
   - 开放 5000 端口

4. 如果选择手动部署(不用脚本)

   ssh root@34.81.122.137

   # 安装 Python3(如已安装跳过)
   apt-get update && apt-get install -y python3 python3-pip

   # 安装依赖
   pip3 install flask flask-cors requests gunicorn

   # 创建目录,放入 server.py
   mkdir -p /opt/pdd-kefu
   cp server.py /opt/pdd-kefu/

   # 设置 API Key
   export DEEPSEEK_API_KEY="sk-你的key"
   echo 'export DEEPSEEK_API_KEY="sk-你的key"' >> /opt/pdd-kefu/env.sh

   # 启动(测试用)
   cd /opt/pdd-kefu
   python3 server.py

   # 或者用 gunicorn 生产运行
   python3 -m gunicorn -w 2 -b 0.0.0.0:5000 server:app

5. 开放云服务器防火墙

   如果用的是阿里云/腾讯云/华为云:
   → 进入云控制台
   → 找到「安全组」或「防火墙」
   → 添加入方向规则:
      协议: TCP
      端口: 5000
      来源: 0.0.0.0/0
   → 保存

6. 验证服务器是否正常

   在你本地浏览器打开:
   http://34.81.122.137:5000/api/health

   应该返回:
   {"has_api_key":true,"status":"ok","time":"..."}


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  第二步: 安装 Chrome 插件
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 生成图标

   在你本地电脑运行:
   cd E:\ai客服
   python create_icon.py

   这会生成 extension\icon.png

2. 加载插件到 Chrome

   - 打开 Chrome 浏览器
   - 地址栏输入: chrome://extensions
   - 右上角打开「开发者模式」开关
   - 点击「加载已解压的扩展程序」
   - 选择文件夹: E:\ai客服\extension
   - 插件安装完成!

   你会看到浏览器工具栏出现插件图标(绿色圆点)

3. 配置插件

   - 点击浏览器工具栏的插件图标(如果找不到,点拼图图标找到它,再点图钉固定)
   - 在弹出的设置面板中填入:
     · DeepSeek API Key: 你的 sk-xxx
     · 服务器地址: http://34.81.122.137:5000
     · 店铺提示词: 根据你的店铺修改(可选)
   - 点击「保存配置」
   - 点击「测试连接」确认一切正常

   测试连接会:
   ① 检查服务器是否在线
   ② 发送一条测试消息给 AI
   ③ 显示 AI 回复,证明整个链路通了

  第三步: 开始使用
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 用 Chrome 打开拼多多商家客服页面
   网址类似: https://mms.pinduoduo.com/...

2. 登录你的商家账号

3. 观察页面右上角,应该出现一个绿色标签:
   「● AI客服 监听中」
   出现这个 = 插件已成功注入 ✅

4. 当有买家给你发消息时:
   - 绿色圆点会变蓝「● AI客服 思考中...」
   - AI 生成的回复会自动填入输入框并发送
   - 发送完成后绿点短暂显示「已回复」然后恢复监听

5. 状态指示器说明:
   🟢 绿色 = 监听中,等待买家消息
   🔵 蓝色 = 正在调用 AI 生成回复
   🟡 黄色 = 已暂停(手动模式)
   🔴 红色 = 服务器连接失败

6. 点击右上角圆点可以切换「自动回复」和「暂停」模式

  常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: 插件加载后,打开拼多多页面没有绿色圆点?
A: 检查几个方面:
   ① 确认网址是 mms.pinduoduo.com 域名
   ② 在 chrome://extensions 中刷新插件
   ③ 按 F12 打开开发者工具 → Console,看有没有 [AI客服] 开头的日志
   ④ 确认 content.js 和 manifest.json 在同一个 extension 文件夹中

Q: 能检测到消息,但回复发不出去?
A: 拼多多可能改了页面结构。按 F12 打开控制台,看是否有
   "[AI客服] 找不到输入框" 或 "[AI客服] 回复已发送" 的日志。
   把控制台截图发给我,我帮你调整选择器。

Q: 服务器日志在哪看?
A: SSH 连上服务器后:
   journalctl -u pdd-kefu -f    # 实时日志
   journalctl -u pdd-kefu -n 50 # 最近 50 行

Q: AI 回复太慢?
A: 正常 1-3 秒。如果超过 5 秒,检查:
   ① 服务器到 api.deepseek.com 的网络延迟
   ② DeepSeek API 服务是否正常(去看看 DeepSeek 状态页)

Q: 如何修改 AI 的回复风格?
A: 点插件图标 → 修改「店铺提示词」→ 保存
   提示词会自动同步到服务器,无需重启。
   提示词里可以写:店铺主营什么、快递用哪家、发货几天等

Q: 想停用自动回复?
A: 两种方式:
   ① 点击页面上方绿色圆点,切到「已暂停」
   ② 在 chrome://extensions 中暂时禁用插件

Q: 服务器重启后需要重新配置吗?
A: 不需要。配置通过 systemd 的 EnvironmentFile 持久化,
   且 API Key 可通过插件的「保存配置」随时更新到服务器。
