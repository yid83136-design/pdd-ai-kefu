============================================
  拼多多 AI 客服助手 —— 完整安装使用指南
============================================

自动监听拼多多商家客服消息 → 调用 DeepSeek AI 生成回复 → 自动发送。
24小时在线，买家消息秒回。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  系统架构
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  买家在拼多多发消息
       ↓
  你的 Chrome 浏览器（打开拼多多客服页面）
       ↓ content.js 检测新买家消息
       ↓ POST 到你的服务器
  你的 Linux 服务器（Flask + DeepSeek API）
       ↓ AI 生成回复
       ↓ 返回回复文本
  content.js 自动填入输入框 → 点击发送
       ↓
  买家收到回复


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  前置准备
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  你需要准备以下东西：

  1. DeepSeek API Key
     → 到 platform.deepseek.com 注册，充值 10 元即可
     → API Key 以 sk- 开头

  2. 一台 Linux 服务器
     → 任意云服务器都行（阿里云/腾讯云/华为云）
     → 1核1G 最低配足够
     → 需要公网 IP

  3. Chrome 浏览器（版本 88+）

  4. 拼多多商家账号（能登录 mms.pinduoduo.com）


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  第一步：部署服务器
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. 把文件上传到服务器

     在你本地电脑打开 PowerShell 或终端，运行：
     （把"你的服务器IP"换成实际 IP）

     scp "E:\ai客服\server.py" root@你的服务器IP:/root/
     scp "E:\ai客服\setup_server.sh" root@你的服务器IP:/root/

  2. SSH 登录服务器

     ssh root@你的服务器IP

  3. 运行一键部署脚本

     chmod +x setup_server.sh
     sudo bash setup_server.sh

     脚本会自动做这些事：
     - 安装 Python3 和 pip3
     - 安装 Flask、requests 等依赖包
     - 引导你输入 DeepSeek API Key
     - 创建 systemd 服务（崩溃自动重启、开机自启）
     - 开放防火墙 5000 端口

  4. 开放云服务器安全组（重要！）

     阿里云/腾讯云/华为云用户必须做这一步：
     → 进入云控制台
     → 找到「安全组」或「防火墙」
     → 添加入方向规则：
        协议：TCP
        端口：5000
        来源：0.0.0.0/0
     → 保存

  5. 验证是否成功

     用浏览器打开：
     http://你的服务器IP:5000/api/health

     应该看到类似这样的内容：
     {"status":"ok","time":"...","has_api_key":true}


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  第二步：安装 Chrome 插件
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. 加载插件到 Chrome

     ① 打开 Chrome 浏览器
     ② 地址栏输入 chrome://extensions 回车
     ③ 右上角打开「开发者模式」开关
     ④ 点击「加载已解压的扩展程序」
     ⑤ 选择文件夹：E:\ai客服\extension
     ⑥ 完成！工具栏会出现插件图标

  2. 配置插件

     ① 点击浏览器右上角插件图标
        （找不到的话点拼图图标 → 找"拼多多 AI 客服" → 点图钉固定）
     ② 在弹出面板中填写：
        · DeepSeek API Key：你的 sk-xxx
        · 服务器地址：http://你的服务器IP:5000
        · 店铺提示词：可选，留空用默认
     ③ 点击「保存配置」
     ④ 点击「测试连接」，确认显示"连接成功"


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  第三步：开始使用
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. 用 Chrome 打开拼多多客服页面
     https://mms.pinduoduo.com/chat-merchant/index.html#/

  2. 确认插件已启动
     页面右上角会出现状态标签：

     🟢 监听中   = 正常工作，等待买家消息
     🔵 思考中   = 正在调用 AI 生成回复
     🟡 已暂停   = 手动关闭了自动回复（点圆点可切换）
     🔴 连接失败  = 无法连接服务器，检查网络

  3. 测试自动回复
     用另一台设备或浏览器，以买家账号给你的店铺发消息。
     插件会自动检测 → 调 AI → 填入回复 → 自动发送。

  4. 切换对话
     插件支持多个买家同时在线。
     点击左侧联系人列表切换对话即可，插件会自动识别。

  自定义 AI 回复风格
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  server.py 已内置完整的客服话术体系（25+ 场景）。

  如果想定制，有两种方式：

  方式一：通过插件面板（推荐，简单）
    点插件图标 → 在"店铺提示词"框写额外要求 → 保存。
    内容会追加在默认 prompt 后面。

  方式二：直接改 server.py（深度定制）
    编辑服务器上 /opt/pdd-kefu/server.py
    找到 SHOP_PROMPT 变量，按需修改。
    改完后重启服务：
    sudo systemctl restart pdd-kefu

  服务器管理命令

  停止服务          sudo systemctl stop pdd-kefu
  查看服务状态      systemctl status pdd-kefu

  常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Q: 插件加载后打开拼多多页面没有绿色标签？
  A: ① 确认网址是 mms.pinduoduo.com 域名
     ② 在 chrome://extensions 点刷新按钮
     ③ 按 F12 → Console，看有没有 [AI] 开头的日志
     ④ 确认 content.js 和 manifest.json 在同一文件夹

  Q: 能检测到消息但回复发不出去？
  A: 按 F12 打开控制台，输入 debugDump() 查看消息定位，
     截图发给我帮你分析。

  Q: AI 回复跟客户问题不相关？
  A: ① 检查 http://服务器IP:5000/api/health 确认正常
     ② 查看服务器日志 journalctl -u pdd-kefu -n 30
     ③ 如果 prompt 是旧的，更新 server.py 里的 SHOP_PROMPT

  Q: 客户发第二条消息不触发？
  A: ① 刷新插件 + F5 刷新页面
     ② 确保 content.js 版本号 ≥ v3.7

  Q: DeepSeek API 报错？
  A: 401 → API Key 错误或过期，重新生成
     402 → 余额不足，充值
     429 → 调用太频繁，稍等再试

  Q: 想临时暂停自动回复？
  A: 直接点击页面右上角的绿色圆点，会变成黄色"已暂停"。
     再点一次恢复。
